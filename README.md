# かわいい島の記憶生活(仮)

まきこ(母)の機嫌を30日なだめ続ける、スマホ縦持ち前提のブラウザゲーム。

- **目的**: まきこのごきげん(0〜100)を保つこと。要求は遠回しにしか言われず、セリフから一意に特定できない。
- **1日**: 朝(感情装備) → 昼(仕事 or 誰かに会う) → 夕方(増減の確認) → 夜(6択から1つだけ) → 就寝
- **ご褒美**: ごきげん70以上で4日連続寝ると、恒久アップグレードを2択で1つもらえる

設計と数値の根拠は [docs/state-design.md](docs/state-design.md) を参照。

## 開発

```bash
npm install
npm run dev        # 開発サーバ(--host 付きなので同一LANの実機からも開ける)
npm run typecheck  # 型チェック
npm run sim        # 30日をヘッドレスで回してエンディング分布を確認
npm run build      # 型チェック + 本番ビルド(dist/)
```

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/game/` | ゲームロジック。React に依存しない純関数(reducer + 設定 + 導出) |
| `src/ui/` | 画面。スマホ最適化(dvh / safe-area / タップ領域) |
| `scripts/simulate.ts` | バランス調整用のヘッドレス試行 |
